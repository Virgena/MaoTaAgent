blmoadll 是一个面向 Node 宿主的插件内核。它启动并监督插件进程，按能力 ID 路由调用，转发事件、流和终端 io。内核不理解模型、会话、工具或 UI。

## 按角色选择

| 你想做什么 | 从这里开始 |
|---|---|
| 写一个插件 | [插件](/docs/plugin) |
| 运行、部署或调整内核 | [内核](/docs/blmoadll) |
| 写宿主、编辑器或应用集成 | [宿主协议](/docs/blmoadll/host) |
| 了解共享进程或 Runtime 形态 | [共享扩展宿主](/docs/blmoadll/shared-host) |
| 排查错误码和超时 | [错误码](/docs/blmoadll/errors) |

## 两个文档区

**内核**：只讲内核自己的职责和行为，包括配置、进程生命周期、能力路由、事件总线、宿主协议、共享扩展宿主和 Runtime。

**插件**：只讲插件作者需要遵守的协议和做法，包括分帧、初始化、处理调用、流式输出、事件、终端 io、日志和发布自检。

## 协议版本

当前协议版本是 3。版本通过 `initialize` 协商，不匹配会得到 -32015，启动直接失败。新增可选字段不算不兼容；删除字段或改变语义才需要提升版本号。
