**读者**：要用 TypeScript 或 Node 写 blmoadll 插件的人。

**结论**：插件就是一个普通子进程。它在 fd 0 上读帧、在 fd 1 上写帧，按 JSON-RPC 应答 `initialize`、`start`、`invoke` 和 `shutdown`，就这些。

## 最小插件

```ts
#!/usr/bin/env node
// 一个用 Node 写的 blmoadll 插件。
import { writeSync } from "node:fs";

const provides = ["demo.text"];
const injects: { capability: string; optional?: boolean }[] = [];
const registrations: { service: string; capability: string }[] = [];
const host_calls: string[] = [];

function send(message: unknown): void {
  const body = Buffer.from(JSON.stringify(message), "utf8");
  writeSync(1, `Content-Length: ${body.length}\r\n\r\n`);
  writeSync(1, body);
}

function chunk(streamId: string, seq: number, data: unknown, done: boolean): void {
  send({ jsonrpc: "2.0", method: "$/stream/chunk",
         params: { stream_id: streamId, seq, data, done } });
}

let buffer = Buffer.alloc(0);

process.stdin.on("data", (incoming: Buffer) => {
  buffer = Buffer.concat([buffer, incoming]);
  for (;;) {
    const split = buffer.indexOf("\r\n\r\n");
    if (split < 0) return;
    const match = /content-length:\s*(\d+)/i.exec(
      buffer.subarray(0, split).toString("latin1"));
    if (!match) throw new Error("missing Content-Length");
    const length = Number(match[1]);
    if (buffer.length < split + 4 + length) return;
    const payload = buffer.subarray(split + 4, split + 4 + length);
    buffer = buffer.subarray(split + 4 + length);
    handle(JSON.parse(payload.toString("utf8")));
  }
});

// 内核关闭 stdin 或要求 shutdown 时，干净离开。
process.stdin.on("end", () => process.exit(0));

function handle(message: any): void {
  const { id, method, params } = message;
  if (method === undefined) return;                 // 一个响应
  if (id === undefined || id === null) return;      // 一个通知，不需要回复

  switch (method) {
    case "initialize":
      send({ jsonrpc: "2.0", id,
             result: { protocol: 3, provides, injects, registrations, host_calls } });
      return;

    case "start":
      // params.capabilities 是整张路由表的快照。
      send({ jsonrpc: "2.0", id, result: {} });
      return;

    case "invoke": {
      if (params?.meta?.stream !== true) {
        send({ jsonrpc: "2.0", id, result: { echo: params?.params ?? null } });
        return;
      }
      // 流式：stream_id 必须先回复，再发 chunk。
      const streamId = `s-${id}`;
      send({ jsonrpc: "2.0", id, result: { stream_id: streamId } });
      for (let n = 0; n < 3; n += 1) {
        chunk(streamId, n, { delta: `chunk ${n}` }, false);
      }
      chunk(streamId, 3, null, true);
      return;
    }

    case "shutdown":
      // 所有 reason 一视同仁：收尾、回复、退出。
      send({ jsonrpc: "2.0", id, result: {} });
      process.exit(0);

    default:
      send({ jsonrpc: "2.0", id,
             error: { code: -32601, message: `no ${method} here` } });
  }
}
```

## 注册到内核

```toml
[plugins.demo]
command = "node"
args = ["minimal-plugin.mjs"]
```

把插件文件和配置放在同一目录，然后运行：

```text
blmoadll blmoadll.toml
```

内核会启动这个进程，执行 `initialize` 和 `start`，之后才把调用路由过来。

## 三个必须避免的错误

**不要往 stdout 写任何非帧内容。** `console.log`、`printf`、进度条、依赖的横幅都会破坏协议。日志写到 stderr 或 `kernel.log`。

**不要在 `shutdown` 之前自行退出。** 在 `initialize` 之后、内核要求关闭之前退出，会被当作崩溃，能力槽变为不可用。

**流式回复必须先发 `{stream_id}`。** 先发 chunk 再发 stream id，chunk 会作为孤儿被丢弃。
